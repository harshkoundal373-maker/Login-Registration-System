# Login and Registration System

## 📌 Project Overview
This project is a simple Login and Registration System developed using Python. It allows users to register with a username and password and then log in using their credentials.

## ✨ Features
- User Registration
- User Login Authentication
- Duplicate Username Validation
- File Handling using JSON
- Success and Error Messages

## 🛠️ Technologies Used
- Python
- JSON
- File Handling

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python login_registration.py
```
